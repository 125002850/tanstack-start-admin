Orientation

课程不是照抄页面，而是追问“为什么”。

适合已经能独立完成普通 CRUD，但希望理解渲染、状态、架构和性能本质的 React 开发者。课程刻意弱化 RSC、Server Actions 和 Next.js SSR，因为本仓库是一套纯 SPA。

学完能够做到

  • 解释 Render、Commit、Effect 与状态保留机制。
  • 选择局部状态、Context、Zustand、URL 或 Query。
  • 设计类型安全、可组合、可测试的组件 API。
  • 定位闭包、竞态、重复渲染和虚拟卸载问题。

推荐学习循环

  • 先画调用链和状态所有权，不急着修改代码。
  • 用一个最小实验验证自己的解释。
  • 阅读同目录测试，理解真正被保护的契约。
  • 最后完成小型改造，并用验证结果复盘。

Capstone Project

交付一个真正属于这个仓库的后台功能。

目标不是展示 API 数量，而是证明你能在现有架构边界内完成一条可靠的业务纵切。

四次迭代

  1. 类型安全路由、metadata、权限和懒加载页面。
  2. Generated Client、React Query 列表、Mutation 与缓存失效。
  3. TanStack Form 新增/编辑 Sheet，以及共享 DataTable。
  4. Workspace 生命周期、未保存保护、Vitest 与 Playwright。

验收标准

  • 能画出交互的数据流和渲染链路。
  • 能解释每个状态为什么属于当前层。
  • 不直接 fetch，不自行调用 useReactTable。
  • 不重复包装 PageContainer，不绕过公共运行时。
  • 能用测试、Profiler 和构建结果证明改动正确。
